# ADR 0034: Deep cobalt frontend renewal

Date: 2026-11-03. Status: accepted.

The existing interface separates the machine model across tabs beside a permanently visible
chat column. Greg reviewed local workspace, identity and project Overview studies, chose the
earlier Overview with deep cobalt and the eagle-eye MF logo, and rejected the later decorative
pattern treatment. Options were to retain the old presentation, add only a new color theme, or
apply the selected workspace structure and visual system throughout the frontend.

Greg approved the full frontend plan: live project Overview, sidebar navigation, on-demand
assistant, shared readable typography/controls, and coherent presentation of existing work areas.
The viewer change uses existing layout data and keeps current capabilities; protected frontend
PLC and rating screens receive presentation changes only. DESIGN.md and the companion frontend
spec record the boundary. Backend responsibilities and engine phase order stay as defined.
